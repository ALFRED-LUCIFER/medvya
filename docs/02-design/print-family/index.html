Medvya print and email family

One layout for every paper and email a clinic sends. The clinic's logo and name lead, a teal rule sits under them, and small labels hang in the start margin beside one calm column, so a patient, pharmacist or lab finds who sent it, who it is for and what to do in that order. Every person, clinic and number here is synthetic.

Token slip · 80 mm thermal receipt

Shown at real size. Black only, because thermal printers print one colour. The token is the biggest thing on the slip. Below the dashed line, today's Wi-Fi: scan the code to join, or type the password. Nothing about the patient is printed.

What changes from today

  • The token goes from a 30 px line to the full width of the slip, so it reads from across the room.
  • Clinic logo (re-drawn in black), address and phone head the slip.
  • "3 ahead of you" is bold, because that is the patient's real question.
  • A tear-off Wi-Fi stub with a join code that works on iPhone and Android cameras.

Needed to build it

  • Wi-Fi network and password per location in Settings, with an option to change the password daily. The slip leaves out the stub when no Wi-Fi is set.
  • The doctor's room, clinic address and phone in the slip data. The room is already on the front-desk board; the slip carries only the clinic name today. No room set: the row is left out.
  • Print the QR code on the clinic's own thermal printer and scan it with two or three phones before going live: thermal paper can blur fine detail.

Prescription · A4 and A5

The same fields and wording as today's prescription, now laid out. The doctor's name, qualifications and registration sit top right where a pharmacist looks first. Allergy is a red block with a shield and the word "Allergy". Medicines are numbered, with the generic name in capitals as NMC guidance asks. The registration number repeats under the signature. The verify QR code is at the foot.

What changes from today

  • One column of run-on lines becomes labelled rows: Patient, Allergy, Diagnosis, Medicines, Stop, Advice, Follow-up.
  • The doctor block moves top right. The registration number is printed again under the signature, as the NMC regulations of 2 Aug 2023 ask.
  • The generic name is in capitals, with strength and form after it in lighter type. Schedule warnings sit in a box under their own medicine.
  • The verify link, QR code and page number share one footer instead of three separate lines.

Before it ships

  • Clinical sign-off: the allergy block and the capitals change how the paper reads, even though the fields and wording stay the same.
  • Raise RxPdfDocument.LayoutVersion to 4, so every doctor approves the new layout again.
  • PlainPdf becomes a small set of QuestPDF building blocks (masthead, labelled row, signature, footer) shared by every paper.
  • A UAE clinic gets the same layout with its licence authority (for example DoH) in the doctor block.

Investigation slip and referral letter · A4

Same masthead, rule, labelled rows, signature and footer. Only the title and the rows change. The signed consultation note uses the same frame, with each addendum as its own labelled row.

Emails

The same masthead and labelled rows in a 600 px email, sent as HTML with the plain-text copy beside it. Patient emails still name only the clinic, the date and the time: no doctor, reason or medical detail. One teal button only where there is something to do.

What changes from today

  • Plain text becomes branded HTML with the clinic logo, and the plain-text copy is still sent for clients that block HTML.
  • The date and time are spelt out and the time zone is named, so nobody misreads 17/11 or 11/17.
  • Clinic address and phone (clinic details, not patient details) tell the patient how to change the visit.
  • The footer says why the email came and how to stop it.

Needed to build it

  • EmailMessage gains an HTML body next to the text body; SMTP, SendGrid and Azure Communication Services all accept both.
  • Table-based HTML with inline styles, because Outlook and Gmail ignore modern CSS. The logo is a transparent PNG at 2×, with the clinic name as its alt text.
  • The SMS text stays exactly as registered under DLT; only the email gains layout.
