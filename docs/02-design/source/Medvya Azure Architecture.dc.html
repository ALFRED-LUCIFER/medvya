Azure deployment architecture for Medvya

Two stages. Phase 1 runs one customer in one region with a production-grade baseline. Full scale runs many solo doctors, clinics and hospitals across India and the UAE using deployment stamps: pooled stamps for small practices, dedicated stamps for hospitals that need isolation. Patterns follow the Microsoft Azure Architecture Center AKS baseline, hub-spoke networking and multitenant SaaS guidance.
