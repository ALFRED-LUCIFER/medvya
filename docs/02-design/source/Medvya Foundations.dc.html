01

Visual direction

Principles
Verified first. Clinician-verified data sits in solid ink. AI output is always violet, labelled "AI draft · not reviewed", and never shares the verified style.
One patient, one banner. Every clinical screen carries a fixed identity banner: name, age, sex, MRN, DOB, allergies, consent and encounter date.
Status is text + shape + colour. Each clinical state has a label and an icon, so colour is never the only signal.
Quiet surfaces. White cards on cool off-white, 1px borders, almost no shadow. Amber and red appear only for real clinical risk.
